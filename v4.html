Juttu v1.0.1 — v4「Digital Life」首个维护版

build 1 TestFlight 已上 对应 PRD v4
TL;DR · 30 秒读完

v4 「Digital Life」上线后第一个维护版本。稳固 session / 配额 / 回流三大流程，把观测黑洞（ingest 任务、Dream Agent、Prompt override）全部点亮，修几条"发消息没回应 / 明明没聊就到限额 / 卡片 Leo 说好 opener 进聊天消失"的体验 bug。

注：本版按当时的「客户端 / PE / 服务器 / 运行时 / 文档」结构记录。新格式（Backend / PE / iOS / Other 四模块）从 v1.0.2 起开始。

Session / 配额 / 回流 三流程稳固

🔁 Session resume 按 (source_type, source_id) 匹配
之前只 topic_card_id == body.topic_card_id，Snippet 的 topic_card_id=None 永远 resume 不到，点同一 Snippet 两次扣两次配额。修复：先 derive source_type/source_id，再查 active session。topic / snippet / prep / return 四种入口 resume 语义现在对称。
📊 Active session map key 扩展
从 {topic_card_id → session_id} 改成 {(source_type, source_id) → session_id}。/feed/instant 的 topic / return / snippet 都能拿到 active_session_id hint，避免 paywall 误触。
🎯 Direct 卡 opening 兜底
若 conversation_type=direct 且有 leo_quote 但 opening 没 Leo，自动用 leo_quote 填 opening_content[1]。修"卡片 Leo 说好 opener 进聊天消失"的体验 bug——81% 的 direct 卡之前只 Nova 在 chat 里出现。
💰 安全 HIGH 事件退款
触发 safety_blocked 的 chat，Free 用户 chat_count_today -= 1。"明明没真聊就扣了一次配额"修复。
🔁 Return session 不扣配额
Return session（Spill it 触发，PRD §7.5）是 deep chat 的 continuation，bypass paywall + 不消耗 daily quota。配合 chat.py 的 is_return_session 分支。

观测黑洞点亮

⚙️ Admin System tab（新）
4 个新 endpoint 监控运行时状态：/system/live-state / /system/scheduled-tasks / /system/agent-runs / /system/run-task/{name}（白名单手动触发）。Admin 后台可以看到所有 cron 跑没跑、Dream Agent 输出、最新 perception batch。
📝 V4 Prompt CRUD（admin）
Admin 后台可以在线 view / edit / delete prompt（/admin/v4/prompts + /{key}），DELETE 恢复 code-level 默认。不动 git 也能验证 prompt 改动效果。
📋 TaskRunLog 接入 3 个 ingest tasks
PR-8.22 把 TaskRunLog 模型接进 RSS / Reddit / Hacker News 三个 ingest tasks，admin 能看到每次跑的状态、抓回数量、失败原因。

其他体验修复

  • Session expired 自动 retry（A 路径）：iOS 端遇到 session expired 时不再直接报错，silent retry 一次
  • 2h Preview reap（B 路径）：服务器侧 active session 2 小时无活动转 expired
  • Pull-to-refresh on Home feed：iOS PR-8.19 加 .refreshable（v4.1-1 时进一步完善）
  • Paywall flow diagnostic logs：iOS PR-8.20 加 [Quota] 前缀的 print，方便排查"明明 pro 还触发 paywall"问题
  • SnippetUI activeSessionId default-nil：PR-8.24 fix，避免 decode 时报错
  • Snippets active_session_id symmetric：PR-8.21 给 snippet 也加同样的 active_session_id 字段（之前只 topic_card 有）

已知限制（带到 v4.1-1）

  • 主屏 feed 内容跨度不够（v4.1-1 加 exploration 解决）
  • 详情页不存在，点卡直接进 chat（v4.1-1 新加详情页）
  • Recap 没有 detail 视图（v4.1-1 新加）
  • Quote ≤150 字符在 feed 上一行装不下（v4.1-1 收紧到 100）
  • 下拉刷新无效（v4.1-1 修）
  • Snippet 用户看不到（v4.1-1 引入 client-side seen ack）
